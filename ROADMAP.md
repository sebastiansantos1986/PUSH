# PUSH roadmap

Developer: Sebastian Santos · Current test release: engine 1.11.0 / Admin 1.3.0 / JamfCheckIn 1.1.1.

## Implemented

- Stable release tracking, explicit YAML deadline overrides and independent hourly toasts.
- Native popup previews with custom icons, appearance, scheduling and separate button results.
- Deadline failure recovery with saved absolute countdowns, guarded retries, backoff and a daily budget.
- Optional compliance wallpaper with custom staged assets, reassertion and personal-background restoration.
- Saved delivery history and passive installed-readiness reporting.
- Opt-in approved third-party app updates and local Entra registration reminders.
- JamfCheckIn integration with target/user-bound update requests; no separate PUSH menu app.
- Separate employee client and IT-only Admin installers.
- Complete configured-client builder with reviewed YAML/images and paused/deferred-monitor modes.
- Rule-based setup suggestions, profile export, artifact manifests and package-build fixture tests.

- Isolated major-offer simulation with presentation settings and a major-only preview package.
- Informational standalone alerts/toasts and Apple hardware compatibility assessment.

## Before a production fleet rollout

- Finish and pilot the live optional-upgrade request/progress/restart route; currently disabled.
- Establish verified Developer ID app/installer signing and notarization.
- Validate management profiles, optional restart TCC attribution, managed authorization and native GUI delivery on an enrolled pilot.
- Exercise actual install/reboot verification and rollback/support procedures on a pilot.
- Optional provider products remain separate managed prerequisites; file presence is not proof of trust or fleet readiness.

The published artifacts are test prereleases. Offline fixture/build success is not a completed fleet pilot.
