PUSH 1.6.0 — Readiness Reporting

Developer: Sebastian Santos

Adds passive scheduled/manual check history for the PUSH Admin readiness dashboard. Existing config repairs, popup previews and update safeguards are retained.

Installs the repaired PUSH command-line tool and popup app for Apple Silicon and Intel Macs running macOS 14 or later.

Your previous PUSH binaries, settings, state, and daemon definition are backed up under /Library/Management/PUSH-backups. Your existing configuration and Keychain credentials are preserved.

The existing automatic schedule will be paused. Installation does not launch PUSH, contact Jamf, download macOS, install an upgrade, or restart your Mac. It refuses to proceed while a known installer or download process is running.

After installation, follow the included test instructions. Automatic scheduling can be enabled separately after local verification.

This package is an unsigned local test build of the repaired source branch. It is not the previous 1.1.7 release rebuilt, and is not signed or notarized for fleet deployment.

End-user password prompts and automatic user-login-password capture are disabled. Keychain checks run without interaction. If managed authorization is unavailable, installation waits for IT.
