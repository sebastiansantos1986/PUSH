PUSH Engine 1.9.1

Developer: Sebastian Santos

Engine component for PUSH Client. The client also installs JamfCheckIn separately; PUSH Admin is IT-only.

Existing policy and state are preserved, previous files are backed up, and monitoring stays paused. No app, check-in, update, desktop change or restart is started by installation.

Local verification build: ad-hoc signed apps, unsigned installer. Read INSTALL-AND-TEST before deployment.
