PUSH Client 1.16.7 / PUSH Admin 1.16.11
Developer: Sebastian Santos — PUSH-DEV-SEBASTIAN-SANTOS

IT MAC: install PUSH-Admin-1.16.11.pkg. The Admin app includes the matching
client and verified Mist package for workflow export/publishing.

EMPLOYEE MAC: deploy the reviewed configured client or optional Self Service
workflow. PUSH-Client-1.16.7.pkg contains PUSH CLI and UI only: no Admin or
JamfCheckIn deployment. Existing JamfCheckIn is left in place.

The standalone client uses paused/dry-run defaults for a fresh installation.
A required-update campaign must explicitly configure and activate monitoring.
Check both auto.enabled and the daemon status when reminders are missing.

Optional Self Service offers use a separate configuration and repeatable repair
policy. A user chooses the offer; prerequisites are verified/repaired on demand,
authorization is resolved, and progress/restart notices follow. No routine manual
uninstall or policy-history reset is required. Required campaign deadlines,
deferrals and installed policy are preserved by the offer path.

Read docs/SELF-SERVICE.md and docs/BUILDING.md for current instructions.
Old 1.9.1 installation instructions are archived in docs/history/.
Local packages are pilot artifacts; complete production signing, deployment
approval and actual upgrade/reboot verification before broader rollout.
