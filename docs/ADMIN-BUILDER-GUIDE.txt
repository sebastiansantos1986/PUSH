Create Workflow: choose tasks, customize messages/icons/images, simulate,
review readiness, then build the configured client with explicit activation.

Jamf Self Service: configure optional macOS generation offers and their wording.
Publish to Jamf: connect your API client, select a pilot, build/review, publish
with policies disabled, inspect names/IDs, then explicitly enable the pilot.
Optional offers and required-update campaigns can be separate or combined.

The matching PUSH Client 1.16.7 and verified Mist CLI 2.3 package are included.
The employee package excludes the Admin app and JamfCheckIn. Existing endpoint
PUSH prerequisites are repaired on demand when missing, older or damaged.

Saved API secrets stay in the admin user's login Keychain. No API secret belongs
in exported YAML, scripts, installer packages or employee Macs. Installed user
update authorization stays in that user's login Keychain and is separate from
the administrator's Jamf API connection.

See docs/SELF-SERVICE.md for permissions, policy behavior and failure recovery;
docs/BUILDING.md for source builds; and the wiki for the other workflow modules.
Old 1.1.0 builder instructions are archived in docs/history/.
